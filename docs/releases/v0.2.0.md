**NEXUS 0.2.0 — Windows x64 (preview).**

Download **`NEXUS-0.2.0-Windows-x64.zip`** below, extract the whole ZIP and run `NEXUS\NEXUS.exe`. To update, replace your NEXUS folder. Your users, saves and settings in `%APPDATA%\NEXUS` are kept.

### Fixed
- **Black screen with a white frame while a game loaded.** The engine created the game window before the game had loaded, and Windows drew it empty. The game window now stays hidden until the game draws its first frame; the NEXUS loading screen is shown until then.

### New
- **Loading screen:** full screen, with the game's artwork, title and the real loading steps. While shaders are prepared it shows the real count (for example "350 of 1000"); no made-up percentages.
- **NEXUS Home while playing:**
  - Press **H** (change it or turn it off in *Settings › Game sessions & saves*) or the controller's **Home/Guide** button.
  - If H is one of your game controls, NEXUS leaves it to the game and tells you.
  - The game keeps running in the background, **muted**, and gets **no input** while you're in NEXUS.
  - Its tile shows a **green dot**. Select it for **Resume Game** or **Close Game**.
- **Performance monitor:**
  - An overlay at the top or bottom of the screen: FPS, frame time, CPU %, CPU temperature, GPU %, GPU temperature, VRAM, RAM and RAM speed.
  - Anything that can't be read on your PC shows **N/A**. CPU temperature currently always shows N/A on Windows (it needs a driver NEXUS doesn't install). GPU temperature is read on NVIDIA cards.
  - Choose the metrics, opacity and size; on for all games or chosen games; toggle it from the game's menu while playing.
- **Frame rate and VSync:**
  - Frame-rate limit for Switch 2 games, 30–240 fps, with presets including 30/60/90/120/144/165/240.
  - **Match my display's refresh rate.**
  - VSync off / on / mailbox, per game.
  - Clear explanations: Switch 1 games run at their own rate; turning off the speed limit makes the game itself run faster rather than adding frames; frame generation adds frames on top.
  - The hardware panel shows your displays' refresh rates.

### Please note
- **Still a preview.** Real games haven't been tested by the project, because the build machines have no graphics card or games. This includes the loading-screen fix in a real game, the overlay, GPU readings, the Guide button and frame-rate limits.
- On Steam or with Steam Input, the Guide button may open Steam instead; use the keyboard key or turn the controller option off.
- Switch 2 support is experimental.

- The engine's interface responded.
- NEXUS's tests passed on Windows and Linux, including the frame-rate settings, the performance monitor's N/A handling and Home with a background session.
