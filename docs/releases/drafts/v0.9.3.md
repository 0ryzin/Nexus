> **Test build (pre-release).** NEXUS 0.9.3. Fixes from Tom's Windows PC logs and the 0.9.3 brief. Not yet tried on the Steam Deck or on Tom's PC; each item says how it was checked.

## New in 0.9.3

- **Account page and Home account indicator no longer go blank** while a synchronisation is running (they waited for it; a slow one runs past a minute).
- **Game saves: safer choice when both devices changed a save.** The choice shows each device's play time and last play and which copy looks further ahead, and starts on *Decide later*, so one press can no longer keep an older save over a more advanced one. Nothing is overwritten without a choice; the one not kept is backed up.
- **Shader import no longer empties a game's start-up shaders.** Importing another device's cache replaced this device's lists of the shaders it uses at start (about 5,000 to 0). The report gives real counts before and after, and *Import Shader Data › Undo the last import* puts back the data from before the import.
- **Texture quality now really applies.** In 0.9.2 the setting never reached the engine; every game ran at Medium.
- **Controllers:** a D-pad fallback on Windows (NEXUS reads Xbox-type controllers' D-pad itself when WebView2 does not report it), sturdier menu input, and the log records what each controller sends.
- **Joy-Con Compatibility** (*Emulation settings › Controls*): Disabled leaves Joy-Cons to the software you use for them (Steam on the Deck, joycond, a Joy-Con tool) so presses do not arrive twice. That software is never changed.
- **GameBanana mods** (*a game's Mods › Browse GameBanana*): search, see a mod's files and install ZIP files, checked like an import (nothing outside the mod, nothing for another game, nothing run, the game's files never changed).
- **Discord Rich Presence** (*Settings › General › Discord*, off by default): shows the game you play in NEXUS; needs a Discord application ID.
- **Windows:** the odd Chinese-named folder next to NEXUS.exe is no longer created and is removed (it was NEXUS's own browser cache under a damaged name).
- **`Customisations/` folder**, kept on updates (nothing uses it yet).

## New in 0.9.2

- **Game artwork now syncs between your devices.** A cover chosen on the PC reaches the Steam Deck and the other way round, picture by picture; the newer picture wins and older ones are kept as backups.
- **Texture quality** (*Graphics*, also per game): High, Medium or Low. High is the default; games you already played keep Medium, as they ran before.
- **Ocarina of Time:** a *Full resolution* switch (*game settings › Frame Rate & Performance*) — off lets the game lower its own resolution when the graphics fall behind, which may help on the Steam Deck.
- **Frame generation:** the built-in method (Lichii Optical Flow) is newer and sharper; it works on any Vulkan graphics, the Steam Deck included. It makes motion smoother, not the game faster.
- **New Steam artwork** for NEXUS in Gaming Mode (the Joy-Con emblem with the NEXUS wordmark), kept up to date by NEXUS after updates; NEXUS can point its Steam entry at a new version instead of adding a second one.

## New in 0.8.1

- **Deleting a save really deletes it.** Account sync used to reinstall a deleted save, so games still offered Continue. The deletion now reaches your account; other devices ask before deleting their copy. The dialog names the user and the game and can delete the game's device save too. Backed up first; refused while that user is playing.
- **Mii Creator.** Each user has their own Miis (*Settings › Users › a user › Miis*), made and edited with a controller, stored in the Switch's own Mii format and given to games when that user plays (the default first). Not yet confirmed in a game.
- **Per-game frame rate** (*game settings › Frame Rate*), separate from frame generation: only rates the engine can really run are offered (Ocarina of Time with its built-in FPS Unlock, Mario Kart World, Hyrule Warriors); every other game says why not.
- **Ocarina of Time on the Steam Deck:** *Play Switch 2 movies (AV1)* can be switched off per game to find the cause of the black screen; the engine log records each movie's format and decode times.
- **Switch 2 memory on the Steam Deck:** explained once per game instead of a warning at every start (12 GB is required and set automatically; it is not 12 GB of RAM).
- **Steam Deck Desktop Mode:** L1/R1, Y and L4 now work when NEXUS is started outside Steam.
- **Amiibo:** NEXUS no longer creates amiibo; import dumps of amiibo you own. Virtual amiibo from earlier versions keep working. When a game scans, the playing user's amiibo come first.

## New Features (since 0.6)

- **Steam Deck, 0.8.0 additions** (not tested on a Deck unless stated):
  - *Add NEXUS to Steam*: one button adds NEXUS to the Steam library with its name, icon and artwork (only while Steam is closed; backup kept; other shortcuts untouched).
  - The in-game performance overlay now works on Linux and the Steam Deck (Gaming Mode: drawn through gamescope like Steam's own overlay), with GPU load and memory, temperatures, clocks, power and battery.
  - A back button (L4 by default) returns to NEXUS Home while the game keeps running.
  - Game artwork (cover, background, title logo) follows your NEXUS account between PC and Deck.
  - *Send this device's logs to my other devices*: a Deck's logs reach your PC through your account.

- **Linux and Steam Deck.**
  - One AMD64 download for every AMD64 Linux PC and the Steam Deck, plus ARM64. Each comes as an AppImage (everything inside) or a tar.gz.
  - On the Steam Deck: add the AppImage to Steam in Desktop Mode and start it in Gaming Mode. NEXUS opens full screen, games open on top, and you return to NEXUS when a game closes.
  - On Linux, NEXUS tells you about new versions; download them from the release page.
- **OOT Launch**, a second startup animation (*Settings › General › Startup animation*), with a gold Home background. The standard animation stays the default.
- **Restore defaults** for every setting, *Reset all settings* and *Restore all keybinds*. Each asks first and says what is kept. Users, saves, games, keys, firmware and the GitHub connection are never reset.
- **On-screen keyboard** for every text field when you use a controller.
- **Search in Settings** and in a game's own settings.
- **Game menu with a controller on Home:** X (the Search button) on a game opens the same menu as a right-click.
- **Switch 2 Pro Controller over USB** (experimental, not yet tested with the controller). On Linux it needs a one-time permission rule, explained in README-Linux.txt; NEXUS never changes your system by itself.

## Improvements

- **Frame generation shows what is really happening.** While a game runs, NEXUS shows whether frame generation is running or why it is not. The built-in method is named for what it is: NEXUS's own frame interpolation for any Vulkan graphics card.
- **GitHub stays connected:** NEXUS renews the sign-in by itself. Connect once more after updating.
- **Settings regrouped** into clear sections, with *Changed* marks and *Advanced* parts.
- **Faster start** when the startup animation is off.
- **Switch 1 fixes from Lichii build 341:**
  - a CPU recompiler race;
  - depth problems at higher resolutions;
  - VP9 video;
  - black water in Switch Sports.

## Bug Fixes

- Typing H, X, Q or E in a search or e-mail field no longer goes Home, opens Options or switches tabs.

## Known Issues

- Linux: Switch 2 games' AV1 movies do not play yet.
- Linux: DLSS and FSR 4 are offered on Windows only.
- Linux ARM64: games are less mature than on AMD64. No game has been tested on ARM64.
- Switch 2 controllers over Bluetooth, and Joy-Con 2, are not supported on Linux.
- Nothing in this release has been tested on a Steam Deck yet.

## Future Development

- Steam Deck testing and tuning.
- AV1 movies on Linux.
