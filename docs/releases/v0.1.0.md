**NEXUS 0.1.0 — Windows x64 (preview).**

Download **`NEXUS-0.1.0-Windows-x64.zip`** below, extract the whole ZIP and run `NEXUS\NEXUS.exe`. To update from 0.0.0, replace your NEXUS folder. Your users, saves and settings in `%APPDATA%\NEXUS` are kept.

### Fixed
- **"Legacy emulator data or an unfinished import was found. Open the Lichii GUI…"**
  - On any PC that had another Switch emulator installed (Eden, yuzu and others), every game failed to start with this message.
  - The cause was a check added in the upstream engine base. It looked at those other emulators' folders and refused to create a configuration.
  - The NEXUS Engine now creates its own configuration in its own folder, and NEXUS handles any import itself. You never need to open or set up another emulator.

- **NEXUS could end with an error when it was closed after a game had been played.** The build's new check found this. The engine's state is now kept until NEXUS exits.

### New
- **NEXUS sets itself up.** On first start, NEXUS creates its engine data folder and configuration on its own.
- **Bringing in data from another emulator:**
  - If NEXUS finds another emulator's data, it tells you what it found and offers to copy it in: keys, firmware, installed updates and DLC, mods, controller profiles and icons.
  - The originals are only read; nothing is changed, moved or deleted. NEXUS backs up its own files first.
  - You can also start fresh and import later in *Settings › System files*.
  - An import that gets interrupted is picked up again at the next start.
- **New way games start:**
  - ***Who's playing?*** shows each user's picture and colour. It's skipped when there's only one user, and can be changed in *Game sessions & saves*.
  - The game's artwork opens with a zoom-and-fade effect.
  - The **NEXUS loading screen** shows the real loading steps: preparing, loading the game, starting.
  - Then the game starts, with play time counted for the chosen user.
- **Clear launch errors.** If a game can't start, NEXUS explains why in plain words. *Technical details* and a **diagnostic log** (`Logs\diagnostics`) hold the engine's own report.
- **[Engine sources](https://github.com/0ryzin/Nexus/blob/main/docs/ENGINE_SOURCES.md):** where the NEXUS Engine's code comes from (yuzu → Eden → Lichii build-150), how Ryujinx relates to it, and what is working, experimental or not supported.

### Please note
- **Still a preview.** Real games haven't been tested by the project yet, because the build machines have no graphics card or games. The same goes for frame generation, DLSS and FSR 4.
- Switch 2 support is experimental.

### Checks this build passed
- The engine compiled, and its test suite passed, including the new data-folder tests.
- The engine's interface responded.
- NEXUS's tests passed on Windows and Linux, including setup, import, start fresh and interrupted import.
- In the ZIP, every DLL the engine needs is either included or part of Windows.
- `NEXUS.exe --engine-check` loaded the engine from a freshly extracted copy of the ZIP.
