> **Test build (pre-release).** NEXUS 0.6.0 is published for testing. It is not offered as an update to installed copies until it has been tested with real games.


## New Features

- **Games inside the NEXUS window.** A game is drawn in the NEXUS window instead of a window of its own. The pause menu and overlays stay with it when you move or resize the window. *Settings › Game sessions › Game window › Separate window* brings back the old behaviour.
- **NEXUS Account with GitHub.**
  - *Settings › NEXUS Account › Sign in with GitHub*. NEXUS shows a code, you enter it at github.com/login/device, and approve NEXUS.
  - Do the same on another PC to link it.
  - NEXUS synchronises your users, play time, game library names and choices, preferences and the amiibo library through a private Gist in your own GitHub account. There is no NEXUS server and nothing to pay.
  - It synchronises automatically: when a game closes, about 10 seconds after a change, and when the connection returns.
  - If the same thing was changed on two devices, NEXUS asks you which version to keep instead of overwriting.
  - Games, keys, firmware, imported amiibo dumps and media are never uploaded.
- **Amiibo.** *Settings › Amiibo*:
  - Import dumps of your own amiibo.
  - Create NEXUS virtual amiibo with the **Amiibo Creator**:
    - search by name, character or series, or type an ID;
    - add your own name, notes and picture;
    - see a preview;
    - edit and duplicate.
  - When a game scans for an amiibo, NEXUS lets you choose one.
  - Virtual amiibo work only in NEXUS and are not authenticated amiibo.
- **Advanced emulation settings**, globally and per game:
  - CPU and GPU clock (Normal, Boost, Overclock);
  - Synchronise core speed and multi-core;
  - speed limit from 10 to 1000 % (presets 50, 100 and 200 %);
  - emulated memory of 4, 6, 8, 10 or 12 GB, checked against your PC's memory.
- **Correct play time.** Open a game's information or *Play time per game*, choose **Correct play time…**, and enter hours and minutes. Play time recorded afterwards is added to it, and the correction is synchronised.
- **Performance overlay redesign.**
  - A thin, translucent strip over the game's picture, with small coloured labels and large values.
  - Or the frame rate only, in a corner.
  - It follows the game when you move the window, resize it or press F11, and hides when the game is minimised.

## Improvements

- **Home is now Shift+H.** H alone goes to the game. You can choose another key or combination in *Settings › Game sessions*. Existing installations still using H are moved to Shift+H.
- **Controllers can be connected while a game runs.** NEXUS maps a newly connected controller to player 1 at once. When the last controller is disconnected, player 1 goes back to the keyboard.
- **The launch animation plays on the game's icon on the Home screen.** The loading screen appears after it.
- **Who's playing?** now has a **Cancel** button.
- A game left running in the background is paused after 15 minutes (adjustable, or never).
- The NEXUS window returns to maximised when you leave full screen, if it was maximised before.

## Bug Fixes

- Keyboard input reaches a game drawn inside the NEXUS window. The game takes the keyboard back whenever it is in front, so clicks and full-screen changes no longer leave it with the NEXUS interface.
- F11 no longer gets stuck. Every press counts, including several quick presses and presses while shaders are compiling or the game is loading.
- **Cancel** on the loading screen stops the game at once. It no longer asks a question that the game could appear over, and the game is not shown afterwards.
- A game played before NEXUS could read its Title ID no longer appears twice in play statistics. Its play time is merged into the game; different Title IDs (regions, editions) are never merged.
- The performance overlay no longer stays at the top of the monitor after leaving full screen.

## Known Issues

- **Not yet tested with real games.** Playing inside the NEXUS window, F11, Shift+H, keyboard and mouse, controller hot-plugging and amiibo in a game have been tested with automated tests and built for Windows, but not yet with a real game.
- **HDR output is not available.** The engine presents in SDR; HDR10 output needs changes to the engine's presentation that have not been made yet.
- Amiibo database search needs an internet connection; virtual amiibo can always be created from an amiibo ID.
- Saves are not synchronised between devices yet.
- NEXUS is not digitally signed, so Windows SmartScreen may warn the first time you run it (*More info › Run anyway*).

## Future Development

- Versions for other operating systems, using the same NEXUS Account.
- Save synchronisation with version history.
- HDR output.
