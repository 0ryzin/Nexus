**NEXUS 0.3.0 — Windows x64 (preview).**

Download **`NEXUS-0.3.0-Windows-x64.zip`** below, extract the whole ZIP and run `NEXUS\NEXUS.exe`. To update, replace your NEXUS folder. Your users, saves, screenshots and settings in `%APPDATA%\NEXUS` are kept. From this version on, NEXUS can update itself (see *Automatic updates* below).

### Platforms
| Platform | Status |
|---|---|
| **Windows x64** | ✅ Available — this release |

### Fixed
- **Controller Home button.** Pressing it could open the game's own "return to the HOME menu?" prompt, flicker between the game and NEXUS, or need several presses. The cause: the button also reached the game as the Switch HOME button, and NEXUS treated every press as a switch back and forth. Now the button never reaches the game, one press goes straight to NEXUS Home (the game keeps its place), and only *Resume Game* goes back.
- **Ocarina of Time (remake) icon.** Switch 2 games packed as NUP (Lichii's format) never got their title or icon from their own files. NEXUS now reads them from the package, for every NUP game.
- **Ocarina of Time compatibility warning.** It came from problems recorded with an older engine. Evidence from an older engine is now shown as history, not as the current status; NEXUS Engine 0.4.0 includes the upstream fix for the Castle Town guard house freeze. The game is not marked as working until it has been played with the new engine.

### New
- **Save Data:**
  - Every user has `UserData\Saves\<PLAYER_ID>-<name>\`, with a folder per game named `<GAME_ID>-<SHORT>` (for example `0400486024DEC000-OOT` with `slot_00 … slot_05`, `account.sav`, `option.sav`). Games read and write there directly.
  - *Settings › Save Data* shows each game's slots and files by name (*Slot 00*, *Account Data*, *Option Data*).
  - **Import saves:** choose a save folder or ZIP. NEXUS shows which player and game each save belongs to (from the folder IDs, or a Ryujinx save's own data). If it can't tell, you choose the game.
  - Export, back up, restore and delete. A save is never replaced or deleted without your confirmation and a backup.
  - Your 0.2 saves are converted at the first start, after a full backup.
- **Media tab:**
  - Press **F12** or your controller's **Share / Capture** button while playing to save a screenshot to `Media\Screenshots`.
  - The Media tab shows each capture with its game and date. You can filter, sort, view, open, show in folder or delete it (to the Recycle Bin).
- **F11** switches a game between fullscreen and a window without restarting it.
- **Smoother start:** the loading screen fades out and the game appears when its first frame is ready.
- **Controllers:**
  - NEXUS remembers your controllers and lets each user choose which one is player 1, 2…
  - A controller can have its own button layout.
- **Game Updates and Mods** in each game's settings:
  - NEXUS checks what a package really contains before accepting it as an update for that game.
  - Mods install for that game only and can be switched on and off.
- **NVIDIA DLSS files:** on GeForce RTX cards, NEXUS can download NVIDIA's Streamline files from NVIDIA's own release. It shows NVIDIA's licences, asks first, then checks the files' checksum and NVIDIA signature.
- **Automatic updates:**
  - NEXUS checks for new releases and shows what's new.
  - It downloads the update, checks it against its published SHA-256, installs it and restarts.
  - If the new version doesn't start, the previous one comes back. Your data is never touched.
  - While the NEXUS repository is private, this needs a read-only GitHub access token in *Settings › Updates*.
- **Engine:** NEXUS Engine 0.4.0 on upstream Lichii build-160:
  - Vulkan pipeline and memory fixes, faster shader compilation and CPU improvements, stability fixes.
  - Fixes for Ocarina of Time (remake), Mario Kart World and others.

### Removed
- Importing system files and data from other emulators (Lichii, Eden, Ryujinx…). NEXUS manages its own system files: install keys and firmware in *Settings › System files*.

### Please note
- **Still a preview.** Real games, controllers and graphics cards haven't been tested by the project, because the build machines have none. That includes the Home button fix in a game, F11, screenshots, controller selection, DLSS and the engine's save folders.
- **Screen recording is not available yet.** Video files placed in `Media\Recordings` are shown and played.
- NEXUS Home pauses the game (it keeps its place) rather than running it in the background.

### Checks this build passed
- NEXUS Engine 0.4.0 compiled from Lichii build-160 + 14 NEXUS patches, and its test suite passed, including the new save-folder test.
- The engine's interface responded.
- NEXUS's tests passed on Windows and Linux: save layout, migration, import, backup, restore, Home presses, media, controllers, updates and mods, the updater and rollback, compatibility history, NUP icons.
- In the ZIP, every DLL the engine needs is either included or part of Windows.
- `NEXUS.exe --engine-check` loaded the engine from a freshly extracted copy of the ZIP and started a session up to the game-file check.
