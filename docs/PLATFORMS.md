# Platforms

| Platform | Status | Download |
|---|---|---|
| **Windows** 10 and 11, x64 (AMD64) | Available (preview) | [Releases](https://github.com/0ryzin/Nexus/releases/latest) |
| **Linux** AMD64 (PCs and Steam Deck) and ARM64 | Built and tested by CI; not released yet | — |

NEXUS is released for Windows only. Linux packages are built by CI ([LINUX.md](LINUX.md)) and are released only after approval. Release pages list Windows only and link only packages that
were built, checked and published.

How the code is kept portable is described in [ARCHITECTURE.md](ARCHITECTURE.md). Android support
is in development in this repository ([ANDROID.md](ANDROID.md)). It is not released and cannot
run games yet.
